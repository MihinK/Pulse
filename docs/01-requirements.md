# Requirements

The canonical, editable requirements document lives here:

**[Pulse — Requirements & Development Plan](https://claude.ai/code/artifact/9d6eb56f-1cb2-4f8f-843e-e8b3a50f9d58)**

It covers: overview and scope, functional requirements (FR-APP-_, FR-HC-_, FR-DOC-_, FR-API-_,
FR-REP-_, FR-USR-_, FR-NOT-*), non-functional requirements (OOP/SOLID/ACID, testing, dates and
numbers, security, performance, operability), the recommended tech stack, and the open
questions log.

We keep it there rather than duplicating it here because it's a live, commentable document —
copying its content into a static file risks drifting out of sync with the version people are
actually discussing and editing. If your team needs an offline copy (e.g. for an assessment
submission), export it from the doc as PDF or Markdown and drop the export in this folder as
`01-requirements-export-<date>.md`, rather than editing this pointer file.
